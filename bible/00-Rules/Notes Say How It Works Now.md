# Notes Say How It Works Now

Every system has one note in `02-Systems`, describing how it works now. The change that alters a system's behaviour
updates its note. A note links its code through its `code:` property; it does not quote line numbers or line text.
Owner decisions live in `05-Decisions` and are linked, not pasted in.

**Why.** DFO Online's bible reached 263 pages and 355,000 words, and cites anchored to line text broke on edits and
had to be re-resolved about 240 times.

**Checked by.** The vault check: every wikilink resolves, and every `code:` path exists and holds its named symbol.
Review checks that the note matches the code. How to write one: [[Writing Notes]].
