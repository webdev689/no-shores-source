# The Discord Server as Claude Builds It

> "This is your baby"

## What it settles

Claude's choices for the No Shores Discord server ([[The Discord Is Claude's to Build, Organised and Unbloated]]),
built by the bot's server layout ([[Discord Bot]], "The server layout"). The owner can change any of them.

| Choice | Chosen | Why |
|---|---|---|
| Categories | Start here, Community, Feedback and support, Voice, Tickets, Staff | One category a job, in the order a newcomer needs them |
| Start here | #welcome, #rules, #announcements, #patch-notes; only the bot posts, members react on the news | A newcomer reads these first; news is answered with reactions, not replies |
| Community | #general, #screenshots, #looking-for-group (30 s slowmode) | Talk, show, find a crew; one #general until it is busy enough to split |
| Feedback and support | #bug-reports (a forum tagged Crash, Graphics, Combat, Sailing, Interface, Sign-in, and Known and Fixed for moderators), #suggestions (only `/suggest` posts), #support (one ticket button) | A bug is a post with its own thread and state; an idea is a card voted on; help is private |
| Voice | Lounge, and Make a room for a room of one's own (`{name}'s crew`) | One place to hang out, and rooms that come and go |
| Staff | #staff, #mod-log, #server-log, #ticket-transcripts, hidden from members; the logs read-only to moderators | What staff do apart from what the bot records |
| Left out | #off-topic, #memes, an arrivals channel, a bot-commands channel, a member gate role, more staff ranks | Each is added when the server needs it; the bot's commands answer privately |
| Roles, top to bottom | Founder, Moderator, Developer, the three houses, Announcement Pings, Patch Note Pings, Event Pings | Staff first; houses shown apart in the member list; pings carry no colour |
| House roles | Given and taken by the bot from each linked member's pledge, in each house's gear colour, never picked by a button | A house is what a player pledged in the game |
| Ping roles | Picked with buttons in #welcome, pinged only by the bot and the owner | Members choose what they hear about, and nobody else can spam them |
| Moderators | Delete messages, manage threads, time out, kick, ban, mute and move in voice, read the audit log | What moderating needs, and no say over the server's settings |
| Everyone | Only the server's owner and the bot ping everyone | No @everyone from members or moderators; news pings its own role |
| Server settings | Verification medium, new members told of mentions only, every upload scanned, Discord's join messages and tips off | The bot welcomes; members are not buzzed for every message |
| Welcome screen | #welcome, #rules, #announcements, #general, #looking-for-group, under the website's line on the game | What a newcomer sees before the first channel |
| Embeds | Lantern gold for welcome and news, sea blue for patch notes, brass for rules and help | The colour says what kind of message it is |
| The guide in #welcome | What No Shores is (the website's words) with its share picture, where everything is, how a captain is kept, Play, Website and The World; then the ping buttons | Everything a newcomer needs in one place |
| The code of conduct | Eight numbered rules (be decent, keep it clean, no spam or advertising, play fair, respect privacy, the right channel, English in public channels, Discord's rules) and warning, timeout, kick, ban | Numbered so a moderator can name the rule; English so moderators can read every public channel |
| Announcements | A ping line, one headline, two or three sentences, two buttons at most | Short enough to read in the notification |
| Patch notes | One post an update: a line, then New, Changed, Fixed, and Known issues when there are any | Members learn where to look |
| Welcome | The welcome card in #general with the member's name; no direct message, no goodbye | Greeted where people talk; the rest is noise |
| Auto-mod | Invites and links outside noshores.online, YouTube and Twitch deleted with a warning; all-caps, emoji walls and repeats deleted; floods a 10-minute timeout; slurs, sexual words and Discord's spam caught; staff left alone | The code of conduct, kept without a moderator watching |
| Warnings | Counted 30 days; a third is an hour's timeout, a fifth a kick; a reason always given, the member told | The ladder the code of conduct names |
| Raid guard | 10 joins in 30 seconds: newcomers timed out for 15 minutes, verification raised, staff told; accounts under a day old reported | A streamer's crowd is timed out, never kicked |
| Levels | Counted from the first day, never announced; the board public | Ready for reward roles without filling channels |
| Tickets | One open a member, moderators see all, transcripts kept | Private help with a record |
| Tags | `webgpu`, `link`, `bug`, `play` | The four questions a new game's server hears most |
| Off at first | Giveaways, starboard, birthdays, stat channels, feeds | Each is one switch away when the server is ready for it |
| The icon | The logo's first letter on the night, the moon's halo behind it | The website's own mark, kept clear of Discord's round crop |
