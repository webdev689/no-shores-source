# The Wreck's Stern Windows Glow

> "Make them glow"

Asked "Should the wreck's stern windows stay dark, or glow like a lit ship's windows at sea?", the owner chose "Make
them glow".

## What it settles

- The stern windows of the prologue's wreck glow as a lit ship's stern windows do at sea
