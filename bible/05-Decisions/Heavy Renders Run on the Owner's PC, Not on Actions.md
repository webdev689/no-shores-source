# Heavy Renders Run on the Owner's PC, Not on Actions

A figures run drew every worn layer of seven moves on GitHub's runners and used about 1,700 Actions minutes in under an
hour before it was cancelled. The owner wrote:

> "This kills my budget"

> "So it sounds like from now on I should always use remote control"

Asked whether to record "heavy renders run on the owner's PC, not on Actions", so future sessions ask before starting
a GitHub render, the owner answered:

> "Yes"

## What it settles

- A heavy render (figure strips, or any forge, Lattice, dungeon-module or ship run of hours of drawing) runs on the
  owner's own PC, through a Claude Code session there or Remote Control once a cloud session can reach it
  (`tools/forge_figures_local.py` for figures, [[Sprite Forge]]).
- A session asks the owner before it starts a render on GitHub's runners by hand or by a request file.
