# The World Editor Draws the Layouts' Buildings

The owner's answer:

> Asked whether the World Editor may import the city layer, the only way it can draw the layouts' buildings, props
> and solids (it drew only their plans): "Yes"

> Asked, once the editor drew them, whether it keeps importing the client's layout folder (to find each layout's
> pieces) as well as the city layer: "Keep it (Recommended)"

## What it settles

- The World Editor's layer may import the city layer and the client's layout layer, and the editor draws each layout's
  buildings, props and solids as the game does ([[World Editor]], [[Layouts]]).
