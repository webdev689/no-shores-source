# Inspect Opens the Character Tab

Asked whether Inspect, in the menu holding Use on a player opens, should take the Character page's layout rather than
the Roster's details, the owner wrote:

> "Inspect should use the character tab"

## What it settles

- **Inspect shows the other player as the Character tab shows the player's own character.**

It changes [[Nameplates, the Interact Menu and Chat as Claude Shapes Them]], whose Inspect was the Roster's details.
