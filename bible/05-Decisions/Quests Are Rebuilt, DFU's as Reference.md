# Quests Are Rebuilt, DFU's as Reference

> "We utilize it as a perfect reference and build a better, more modern quest system. More organization with less
> bloat."

## What it settles

- Overlook gets a new quest system of its own. DFO's quest machine, translated from Daggerfall Unity, is the
  reference to learn from, not code to bring over.
- DFO's own quest layer (questlines, sharing, guidance) informs the design; its scripts, written in Daggerfall
  Unity's script language, do not carry as they are.
- See [[More Organisation, Less Bloat]].
