# Each Continent Is One Biome

> "So with all of this said, I'll need the link to create the continents. Each will be one biome now instead of
> multiple"

## What it settles

- Each of the nine continents is a single biome. A continent's main biome is no longer varied across it into others,
  as [[The World Map]] first had it.
- Which biome each continent is stays the owner's choice, still from DFO's climates.
