# Servers on Dedicated-Core VPS

> "VPS?"

> "Dedicated-core VPS"

## What it settles

- The Rust game servers ([[Server-Authoritative Multiplayer]]) run on virtual private servers whose CPU cores are
  reserved for us, so the simulation keeps a steady step under load.
- Busy regions can move to whole machines later, when load calls for it.
