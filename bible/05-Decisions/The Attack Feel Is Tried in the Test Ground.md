# The Attack Feel Is Tried in the Test Ground

> "So, the attack animations we recently went into rendering are really rough. I'm checking in with the other session
> to see if we can build news ones. In the meantime, I'm wondering if there's a way to beef up the feel without having
> to rerender. Like a seperate attack visual?"

Asked which effects to build as switches in the Test Ground, the owner chose all four (swing arc, hit-stop, camera
kick, lunge):

> "I really want swing arc espcially to be visually appealing. Not a simple half assed implementation. Take your time
> and ensure each of these are implemented perfectly and extremely detailed"

## What it settles

- **Four effects over the blows, no new frames.** A swing arc, a hit-stop, a camera kick and a lunge, each switched
  and set in the [[Test Ground]]'s panel.
- **The swing arc above all** is to be visually appealing and detailed.
- They stay in the Test Ground to be tried; the game takes any of them only once the owner says so.
