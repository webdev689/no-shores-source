# Commons Drop as Themselves, Never as Vestiges

> "Commons should drop, no vestiges for commons"

## What it settles

- **A Normal piece drops as itself**, never sealed in a Vestige; a Vestige is Magic or finer
  ([[Every Drop Wears Its Content's Set, With Random Perks]]).

How it works: [[Gear]], "Vestiges".
