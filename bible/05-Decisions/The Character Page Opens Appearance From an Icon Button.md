# The Character Page Opens Appearance From an Icon Button

> "Along with these changes I want to change the character UI. Adding an icon button in replace of the emblem slot
> that opens up the menu where you can equip emblems, armor dyes, your mount, all with display.
>
> The art UI should also recieve detailed representation with these new changes."

## What it settles

- **The Character page's Emblem slot gives way to an icon button**
  ([[Cosmetics Follow Destiny, Shown in Many Places]]).
- **It opens a menu to equip emblems, armour dyes and the mount, with a display** of what is worn.
- **The Art's screen shows the Arts' levels and what comes with them, in detail**
  ([[Three Factions Keep the Arts, After Destiny 1]], [[Arts Are Overlook's Subclasses]]).
- How it looks is Claude's: [[Factions and Vendors as Claude Shapes Them]].

Replaced in part by [[Horses Are Items Worn in a Mount Slot]]: the menu equips emblems and dyes; the horse is an
item worn in the Mount slot, and the display draws no horse.
