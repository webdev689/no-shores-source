# The World Map

> "We decided the scale is 1:1 with tamriel's size.
>
> 9 continents in total with size ranges with daggerfall as a reference on the lower end and Hammerfell on the higher
> end.
>
> These should be spread out amongst the oceanscape.
>
> Each continent recieves its own main biome with each main biome receiving variations to keep these large land
> masses distinct.
>
> The open sea is populated with much smaller non-continent sized islands, each with one biome. These are static and
> persistant within the world.
>
> Between continents and static isles, are discoveries. Non persistant islands that players can stumble upon. Much
> like how dungeons work in the open world of DFO.
>
> The entirety of the map recieves DFO's dynamic weather, cloud rendering, etc"

The owner's answers to the questions that followed:

> Which Daggerfall is the smallest continent's reference: "Daggerfall's whole map"
>
> What 1:1 fixes: "The whole map frame"
>
> How the continents are placed: "Hand-placed by us"
>
> How long distances work: "1. Faster ships 2. Overworld makes its triumphant debut with ships receiving more speed in
> the overworld also"
>
> Who sees a discovery: "Shared, like DFO's dungeons"
>
> When a discovery goes away: "When nobody's near it"
>
> How many static isles: "#3 - Hidden until discovered. Whomever makes the first discovery will always have their name
> attached (Player discovered)"
>
> The continents' main biomes: "Start from DFO's climates"
>
> Hidden from whom: "Hidden from the player. Fog of war."
>
> Which nine climates: "Decide later"

## What it settles

| Part | Settled |
|---|---|
| The world | Tamriel's frame at DFO's scale: about 4,915 × 3,072 km, ocean included (6,000 × 3,750 map pixels of 819.2 m) |
| Continents | Nine, hand-placed and outlined by us; each from Daggerfall's whole map (about 161,600 km² of land) up to Hammerfell (about 940,000 km² on DFO's map) |
| Main biomes | One per continent, starting from World 2.0's ten climate profiles, each varied across its continent so the land stays distinct; which nine is decided later |
| Static isles | Thousands, each one biome, static and persistent; each player's map is fog of war, so an isle stays hidden from a player until they find it; the first discoverer's name stays attached for good |
| Discoveries | Non-persistent islands between the continents and the isles, shared like DFO's spawned dungeons; each fades a while after the last player leaves |
| Weather | DFO's dynamic weather and cloud rendering over the whole map |
| Travel | Ships sail faster than real speed; DFO's Overworld comes over, and ships go faster still in it |
