# Elite and Abyss Dungeons Are Queued From a Playlist Beside Each Port

> "Looking at the reference, Elite, Abyss matchmaking content should be available in a Playlist icon around each of
> the 3 port cities. For now these are only dungeons.
>
> Instead of these being hidden within the journal ui, this node should open the Playlist UI and allow players to
> queue up and farm this content. With the modifiers, weekly reward indicators if not complicated. I also want to
> implement daily rewards also, plus players can still farm for general rewards.
>
> This UI and matchmaking ties into the same pool in every city."

The reference was Destiny 2's Vanguard screen: a Vanguard Ops, a Nightfall and a Grandmaster Nightfall node, each a
playlist, beside the Vanguard's rank and streak.

> "Please go above and beyond with this, take autonomy, and return when everything is 100% complete"

Shown the first Playlist screen, four tiles of words side by side:

> "The playlist UI is really bad"

## What it settles

- **A Playlist node stands beside each of the three port cities**, Overlook, Sunspire and Rimeholt, on the map.
  Choosing it opens the Playlist screen rather than landing.
- **The Playlist holds the Elite and the Abyss matchmade content**, dungeons alone for now. Players queue from it and
  can farm it, rather than finding it in the Journal.
- **It shows the modifiers and the weekly rewards**, and **pays daily rewards**; each run still pays what a run pays.
- **One pool**: the Playlist and its queue are the same from every city.
- **The screen follows the reference**, not a board of words.
- **How it is shaped is Claude's call**, on the owner's autonomy, recorded in
  [[The Playlist and Its Dungeons as Claude Shapes Them]] and open to the owner's change.

How it works: [[Activities]], "The Playlist".
