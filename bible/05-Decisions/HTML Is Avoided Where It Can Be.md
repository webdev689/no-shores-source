# HTML Is Avoided Where It Can Be

> "Avoid HTML when possible"

Asked what that should cover (Claude's throwaway test pages, the game's interface, or the pages Claude shares with
the owner), the owner answered: "In general".

## What it settles

- Wherever a thing can be made without HTML, it is, in general: not only a page made to test or measure something,
  but the game's interface and what is shared with the owner.
