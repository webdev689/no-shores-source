# HTML Is Avoided Where It Can Be

> "Avoid HTML when possible"

Asked what that should cover (Claude's throwaway test pages, the game's interface, or the pages Claude shares with
the owner), the owner answered: "In general".

## What it settles

- "Avoid HTML when possible", in general: in a page made to test or measure something, and in what is shared with
  the owner.
- The game's interface goes further, with no HTML at all ([[The Interface Uses No HTML, Now or Later]]).
