# Names Follow Guidelines, Checked by the Accounts

> "Definitely need guidelines/a system for account names, guild names, motto, etc"

Asked whether a guild's motto needs rules beyond one plain line, the owner answered as above.

## What it settles

- **Account names, guild names and mottos follow guidelines**, and a system checks them.

## Claude's calls

How the guidelines and the system work is Claude's, each with its reason. The owner can change any. How it works now
is in [[Names]].

| Call | Chosen | Why |
|---|---|---|
| One judge | One place in the accounts judges usernames, guild names, tags and mottos | The server is the authority, and one place keeps every kind alike |
| The kinds' shapes | Each keeps the letters and length it had | They were already plain and fair |
| The list | 79 roots of slurs, obscenities and sexual terms in English, written for Overlook, kept in ROT13 | [[Own Work]]; ROT13 keeps the words off the repo's pages and searches |
| What the list leaves out | Words that hide inside common words and names, such as one inside "Saltwater" | A list that refuses ordinary names does more harm than the word it stops |
| The matching | Lower case, accents dropped, look-alike digits and signs read as letters, a run of a letter once | These are the usual disguises |
| Where a root counts | Four letters or more inside a word, or across words that spell it whole or begin it in spaced letters; shorter only as whole words | Catches "f u c k" and "blow job", yet passes Cassandra, Sussex, "Push it" and "Bit Chasers" |
| A double letter kept | A root spelled with a double letter is matched with it | So Niger and Nigeria pass |
| Reserved names | Admin, moderator, staff, owner, Overlook, official, system, support, GM, dev, server, guest, null and the like, as the whole name or its first or last word, for names and tags | No name may seem to speak for the game |
| Look-alikes | A new username or guild name is refused when it looks like one kept: 0 as o, 1, l and \| as i, 5 as s, rn as m, vv as w, no separators | No one passes for another player or guild |
| Names already kept | Of usernames that already look alike, the oldest holds the skeleton; none is renamed by the change | No player loses a name they hold |
| The refusal words | "That name is not allowed. Choose another.", "That name is too like another player's." (or guild's), "That motto is not allowed." | Plain, and never saying which word, as naming it teaches the way round it |
| One that gets through | Found from the Roster's "An offensive name" reports, kept in the database | The owner already reads reports there |
| The rename | The owner renames an account or guild with one SQL statement through Wrangler, which sets the skeleton too | No route or key is added: rules for keys and security need the owner's approval |
