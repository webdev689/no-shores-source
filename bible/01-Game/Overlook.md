# Overlook

What the game is, in the owner's words. Nobody else writes this note: the design grows as we build it, and each
decision is recorded in [[Decisions]].

> "A proper pirate sandbox experience with goals of venturing into MMO territory. Everything built by us with 0
> bethesda assets."

> "This isnt to be some half assed project. This is going to be ours."

> "Please do not make up your own vision for what I want this game to be. We build it as we go"

> "More organization with less bloat. Thats the goal of this project"

> "A shared world instead of an MMO. A main island acting as a social space and other locations being almost sharded
> shared instances, proper mission structure, gear based power, weapon upgrades, etc"

The scope in full is in [[Overlook Is a Shared World After Destiny 1]].
