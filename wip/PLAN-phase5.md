**Goal.** This phase builds step 5 of the approved Activities design. It has four parts:
- One engine counts what bounties and side quests ask: foes of a faction or rank felled on an island, resource nodes gathered, ships sunk or taken in a water, and dungeons cleared. The room counts each feat as it happens. The account keeps the count: `Character.activity` for bounties, `Character.story` for quests.
- The bounty board stands free in Overlook's plaza and opens after the prologue. It offers six bounties a day, drawn by the clock's day and the same for everyone: two on land, two at sea and two in dungeons. A character takes any of them at the board. Each pays XP and Aurem once when turned in there, and all of them end at the daily reset.
- Side quests use the same objectives as data (`content/story/quests.json`, empty now). They are kept until finished. The missions will write them.
- The sea's count is built behind one small adapter that compiles without #75. One line wires it once #75's `ShipDown` is on the stack.

**Architecture.**
- **The rules, in `gear`.** All rules live in `gear`, which the server and the browser both run.
  - `objectives.rs` holds `Objective` (what is counted), `Feat` (what a room saw) and `Character::saw`. One call counts a feat into today's bounties and into the side quests held.
  - `bounties.rs` holds the board's draw, over Phase 2's `activities::drawn` with a new draw kind, 4. It also holds the pay, and the take and turn-in asks.
  - `quests.rs` reads the quests' data, and takes and finishes a quest.
- **The room.** `crates/room/src/bounties.rs` knows the room's island and calls `saw` from three places:
  - `pay_kill`, for each player who shares the kill;
  - the gather answer;
  - `keep_cache`, for each player in the room as the cache opens.
- **The board's counter.** The bake writes it on its own node-file key. room-wasm turns that key into a `CounterKind::Board` counter, and `counter_for` sends the two bounty asks there.
- **The wire.** The gear message carries the day and the day's six bounties as they stand for the player.
- **The page.** E at the board opens its screen in the menu, as a vendor's stall does. This Week's Bounties section shows the same rows without presses.
- **At sea.** No character is held at sea, so room-wasm keeps each ship that went down in the sea's tick. The sea host claims each fighter's kept character only while no other room holds it. It counts the ship through the rules (`count_kept`) and lets the character go at once.

**The board's model.** A forged prop that could serve does exist: the Prop Forge's `signFrame` family (classic ids 43702 and on, `client/src/models/familiesOutdoor.ts`). But the plaza draws no forged props. Using one would need a drawer like `entranceView.ts`, about 150 lines on the GPU. A Blender piece would need a pipeline like `tools/dungeon`. The smaller option that looks right is neither. The board is built from the courtyard's own solids, as the counters and their goods are: Timber posts and face, Plaster notices, a Roof gable and one Glow lamp. `plan.social.solids` then draws, collides and lights it with no new code.

// objectives.rs
/// The faction and ranks the board names, as `foes` and `naval` number them.
pub const GREY_TITHE: u8 = 1;
pub const ELITE_RANK: u8 = 3;
pub const MINIBOSS_RANK: u8 = 4;
/// What an objective counts: one each time the room sees its feat. Each none is any; a rank counts it and every rank
/// above. Read from the board's table and the quests' data, never kept with a character.
#[derive(Clone, Debug, PartialEq, Eq, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Objective {
    Fell { faction: Option<u8>, rank: Option<u8>, island: Option<String> },
    Gather { resource: Option<u8> },
    Sink { water: Option<String>, rank: Option<u8> },
    Clear { island: Option<String>, tier: Option<Difficulty> },
}
/// What a room saw happen: a foe felled, by each player who shares its kill, by its faction, rank and island (a
/// continent's id; none where the room knows none); a resource node gathered, by its resource's place in the
/// catalogue; a ship sunk or taken, by her water and rank; a dungeon cleared, by its island and tier.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Feat<'a> {
    Felled { faction: u8, rank: u8, island: Option<&'a str> },
    Gathered { resource: u8 },
    Sunk { water: Option<&'a str>, rank: u8 },
    Cleared { island: Option<&'a str>, tier: Difficulty },
}
impl Objective { #[must_use] pub fn counts(&self, feat: &Feat<'_>) -> bool; }
impl Character {
    /// Counts a feat toward each bounty held today, up to its target, and each side quest held: whether a count moved.
    /// A room whose day is not the record's counts no bounty: before it the board was another, after it they ended.
    pub fn saw(&mut self, feat: &Feat<'_>, day: u64) -> bool;          // saw_with(feat, day, &quests().quests)
    pub(crate) fn saw_with(&mut self, feat: &Feat<'_>, day: u64, quests: &[Quest]) -> bool;
}
// bounties.rs

#[derive(Clone, Debug, PartialEq, Eq)]

- **`counts`.** A feat counts only against an objective of its own kind:
  - a faction or a resource must be equal;
  - a rank or a tier must be at least the objective's;
  - an island or a water must equal the feat's, which must be known.

  Each test uses `Option::is_none_or`.
- **`saw_with`.** First the bounties, then the quests:
  - When `day == self.activity.today.day`, take each held `(place, count)` whose `board(day)[place]` counts the feat and is below its target, and add one.
  - Do the same for each held quest found in `quests` by its id, up to its target. A held id that the content no longer has is skipped.
- **The draw.** For each pool `p` of `[LAND, SEA, DUNGEONS]`:
  - `first = drawn(day, BOUNTY_DRAWS, 2p, len)`;
  - `other = drawn(day, BOUNTY_DRAWS, 2p + 1, len - 1)`;
  - `second = if other >= first { other + 1 } else { other }`;
  - places `2p` and `2p + 1` hold `pool[first]` and `pool[second]`.

  The pools are `static`s, in this order:

  | Pool | Objective | Target | Words |
  |---|---|---|---|
  | LAND | `Fell { faction: Some(GREY_TITHE), rank: None, island: None }` | 30 | "Defeat 30 Grey Tithe foes." |

  | LAND | `Fell { faction: None, rank: Some(MINIBOSS_RANK), island: None }` | 2 | "Defeat 2 foes of Miniboss rank or higher." |

#[test]
fn a_side_quest_counts_until_its_target_and_pays_once_when_finished() {
    let quest = Quest {
        id: "a-test-of-the-tithe".into(),
        words: "Defeat 2 Grey Tithe foes on Saltmere.".into(),

        aurem: 40,

    assert!(!character.take_quest(&quest), "held already");
    assert!(!character.finish_quest(&quest), "not done");
