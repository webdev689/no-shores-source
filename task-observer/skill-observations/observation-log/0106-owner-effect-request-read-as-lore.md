**Issue:** The owner's first message named an effect and a lore worry. Claude answered only the lore half (three
framings), and the owner chose one; the next round of questions then built on the wrong picture, and the owner had to
say "When I said respawn effect. I meant for like a translator from destiny". Asking first what the effect should look
like, or what game's effect it is like (the owner often names Destiny), would have saved a round and an edited
decision note.

**Proposed:** when an owner names an effect or feature alongside a lore question, ask what it should look like (or
which game's version they picture) in the same first round as the lore options.
